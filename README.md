# המאמן של דור

אפליקציית ווב אישית (PWA) לאייפון: אוכל, שתייה, משקל ואימונים — לפי התוכנית לירידה במשקל עם כבד שומני.

- **התקנה:** פותחים את הכתובת בספארי ← שיתוף ← "הוסף למסך הבית".
- **נתונים:** נשמרים רק על הטלפון (localStorage). אין שרת ואין חשבון. גיבוי: מסך "שבוע" ← "שמור קובץ גיבוי".
- **עדכונים:** כל דחיפה ל-`main` מתפרסמת ב-GitHub Pages. בכל שחרור מעלים את `CACHE` ב-`sw.js` ואת `APP_VERSION` ב-`app.js`, והאפליקציה תציע "רענן".

## קבצים
- `index.html` — מבנה ועיצוב
- `app.js` — כל הלוגיקה: ספריית מנות, לו״ז יומי, מודל שתייה, אימוני A/B, גרף משקל, גיבוי
- `sw.js` — עבודה בלי אינטרנט
- `manifest.webmanifest`, `icons/` — התקנה למסך הבית
